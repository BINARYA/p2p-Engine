# Suggested Scope - PROP-006

## Included

- Definire schema `.p2p/agent-integrations.yml`.
- Aggiungere comando `p2p agent list`.
- Aggiungere comando `p2p agent install codex`.
- Aggiungere comando `p2p agent install generic --target <dir>`.
- Spostare la skill Codex attuale verso template installabile.
- Documentare pattern presi da Spec Kit/OpenSpec.

## Excluded

- AI adapter diretti.
- MCP.
- Web UI.
- Supporto completo a 20+ tool nel primo step.
- Uninstall distruttivo senza manifest/hash.
