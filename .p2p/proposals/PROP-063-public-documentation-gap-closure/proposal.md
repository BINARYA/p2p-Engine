# PROP-063 - Public Documentation Gap Closure

## Status

`draft`

## Problem

The public README now presents P2P Engine as usable, but several linked operational guides still identify themselves as scaffolds and the repository lacks tutorial, glossary, and public contribution hygiene files.

## Context

Pending.

## Goals

- Make the public documentation coherent enough for a new GitHub visitor to install, understand, try, and safely contribute to P2P Engine.
- Promote CLI and MCP docs from placeholders to practical minimum guides.

## Non-Goals

- Rewrite all design vision documents or produce exhaustive command reference coverage.

## Proposal

Add a tutorial, glossary, real CLI and MCP guide content, HTTPS-first install instructions, and minimal public repository hygiene files.

## Acceptance Criteria

- README and INSTALL do not send public users to SSH-first clone commands.
- CLI and MCP docs no longer present themselves as empty scaffolds.
- A new user can follow one tutorial from rough idea to accepted proposal and Change Set.
- The repo includes minimal CONTRIBUTING, SECURITY, CHANGELOG, ROADMAP, SUPPORT, issue template, and PR template files.
