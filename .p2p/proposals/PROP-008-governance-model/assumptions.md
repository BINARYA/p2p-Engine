# Assumptions - PROP-008

- Il progetto e ancora in bootstrap.
- Il default iniziale puo essere `owner_decides`.
- Git fornisce audit, non permessi applicativi completi.
- Le decisioni finali restano umane o governance-defined.
- La SWOT e supporto alla scelta, non scelta automatica.
- I privilegi reali arriveranno con Git hosting o web backend.
