# Alternatives - PROP-002

## Alternative A - CLI-guided exploration

Pros:

- Deterministic
- Easy to validate
- Fits MVP prompt-only strategy

Cons:

- Less conversational than an agent-led flow

## Alternative B - Skill-guided exploration

Pros:

- Natural conversational experience
- Codex/Claude can ask adaptive questions

Cons:

- Requires strong skill instructions
- Must still persist results through P2P artifacts

## Alternative C - Direct AI adapter exploration

Pros:

- Smooth user experience
- CLI can generate and save outputs directly

Cons:

- Requires provider configuration
- Adds complexity too early
