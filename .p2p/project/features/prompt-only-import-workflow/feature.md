# Prompt-only Import Workflow

## Provenance

- Proposal: PROP-004
- Source: .p2p/proposals/PROP-004-prompt-only-import-workflow

## Problem

P2P Engine genera prompt per varie fasi, ma non importa ancora in modo uniforme gli output prodotti da AI o agenti esterni.

## Proposal

Implementare comandi import uniformi per le fasi successive a explore e aggiungere synthesize prompt/import.

## Decision

# Decision - PROP-004

## Status

`accepted`

## Outcome

accepted

## Reason

Il workflow prompt-only deve essere completo: ogni fase che genera prompt deve poter importare l'output prodotto da AI, agenti esterni o dall'utente.
