# P2P Engine Constitution

## Purpose

P2P Engine exists to transform collaborative discussion into governed proposals, decisions, execution plans, tasks, and actions.

## Principles

1. The proposal is the central unit of work.
2. AI assists the process but does not make final decisions.
3. Decisions must be explicit, traceable, and reviewable.
4. Git is the source of truth for history, auditability, and portability.
5. GitHub, GitLab, Jira, Linear, OpenSpec, and Spec Kit are downstream integrations, not required foundations.
6. Markdown is used for human-readable artifacts.
7. YAML is used for structured data.
8. The CLI comes before the web app.
9. The MVP must validate the workflow before adding managed AI, MCP, billing, users, permissions, or dashboards.

## Bootstrap Rule

Until P2P Engine exists as a working CLI, the P2P method is applied manually through the `.p2p/` file structure.
