# Relevance Criteria

Comments, contributions, and objections should be evaluated using these criteria:

- strategic alignment
- user value
- implementation feasibility
- risk reduction
- architectural impact
- cost impact
- security impact
- legal or compliance impact
- urgency
- evidence quality
- decision impact

## Relevance Classes

- `blocking_objection`
- `major_concern`
- `minor_concern`
- `suggestion`
- `clarification`
- `evidence`
- `duplicate`
- `out_of_scope`
