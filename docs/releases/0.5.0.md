# P2P Engine 0.5.0 — Unreleased

This is the maintained release-note template for P2P Engine 0.5.0. It must
remain marked `Unreleased` until the owner starts the separate release step and
records the actual publication date in `CHANGELOG.md`.

P2P Engine 0.5.0 is a clean break around workspace schema 4, portable vertical
schema 3, project-owned structure, structure-aware memory and readiness,
AuthorityContext, mutation receipts and registry-v2 domain discovery. Git and
GitHub remain external source/release tooling rather than P2P runtime behavior.

## Breaking boundary change

The Git and synchronization product surfaces have been removed. The 0.5.0 CLI,
MCP server, services and generated agent instructions do not initialize or
synchronize repositories, manage remotes or proposal branches, create draft
commits, request reviews, merge, push, publish releases, or drive a branch-based
Work lifecycle. Accepted proposals, Change Sets and completed Work records are
project-state evidence and never proof of implementation. Repository delivery
uses separately authorized external tooling.

## Install

After publication, install the exact release wheel from the GitHub Release:

```bash
python -m pip install \
  https://github.com/BINARYA/p2p-Engine/releases/download/v0.5.0/p2p_engine-0.5.0-py3-none-any.whl
```

Python 3.11 or newer is required.

## Compatibility

Version 0.5.0 supports workspace schema 4 and portable vertical schema 3 only.
It does not provide in-runtime migration or compatibility aliases for older
workspace or vertical schemas. Recreate or externally convert older disposable
development workspaces before enabling governed writes.

## Checksums

The GitHub Release will contain `SHA256SUMS` for the exact wheel and sdist.
Checksums prove downloaded-byte identity; they are not signatures.

## Provenance

The tag-triggered release workflow will create a GitHub Artifact Attestation
for the exact wheel, sdist and checksum file. Users may verify a downloaded
artifact with:

```bash
gh attestation verify p2p_engine-0.5.0-py3-none-any.whl \
  --repo BINARYA/p2p-Engine
```

The attestation is generated only for a release tag, not for normal pushes or
pull requests.

## Repository hygiene

Generated `outputs/`, working `drafts/`, local `specs/` history and generated
demo projects are not release source. The repository tracks only
`examples/README.md`; demos must be regenerated with the exact runtime being
tested.
