# Support

P2P Engine is early-stage and currently supported through repository issues.

Use issues for:

- installation problems;
- CLI or MCP behavior that differs from the docs;
- documentation gaps;
- reproducible bugs;
- feature proposals with clear scope.

For security concerns, follow [SECURITY.md](SECURITY.md).

When reporting a problem, include:

- operating system;
- Python version;
- install method;
- command run;
- relevant output;
- whether the project already has a `.p2p/` workspace.
