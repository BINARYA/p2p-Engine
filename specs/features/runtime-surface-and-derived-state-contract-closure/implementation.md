## S3 Source Ownership

The deterministic renderer consumes:

- Change Set `change.md` physical bytes for frontmatter, title, summary,
  exclusions, deliverables and acceptance criteria.
- Change Set `tasks.yml` physical bytes for commands and acceptance task lines.
- Included proposal `proposal.md` physical bytes for proposal ID, title and
  proposal body.

The renderer input model was narrowed to these consumed files. It does not
fingerprint proposal decisions, unrelated proposals or project-wide
projections.

Legacy provenance classes:

| Shape | Classification policy |
| --- | --- |
| Current reserved block, `origin: generated` | compare source fingerprint and complete candidate bytes |
| Current reserved block, `origin: imported` | `unknown_origin` unless a supported external contract exists |
| Old `source` plus coherent `generated_from` and matching non-provenance files | `current_legacy` |
| Recognizable old generated provenance and differing candidate | `stale` |
| Malformed, ambiguous or unmarked imported content | `unknown_origin` |
| Missing required file | `incomplete` |
